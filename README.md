# 合庫標準範本自動排版系統

同一入口提供 Word 速報排版與財金新聞信件排版。

## 財金新聞信件排版

1. 選擇「財金新聞信件排版」。
2. 上傳 DOCX 或 TXT（10 MB 以下），也可直接貼上文字。
3. 修改主旨、開場問候，按「產生信件預覽與下載」。
4. 下載 EML 草稿、HTML 或 TXT。HTML 可用瀏覽器開啟，選取內容複製到郵件編輯器。

預設保留原文；可選擇去除字數、播放時間及相鄰重複文字。支援範本中的「本文共…字」新聞結構、Word 標題樣式及手動 `## 標題`。其他內容保留為單篇，請先檢查分篇；需要多篇時可在各標題前加入 `## `。

此版本為文字信件：會擷取表格文字，不保留表格版面、圖片、圖表及文字方塊，不改寫新聞、不自動寄送，也不呼叫外部 AI 服務。EML 的編輯模式依郵件軟體而異。產生後若修改內容，必須重新產生才能下載。

## 執行與測試

```sh
pip install -r requirements.txt
streamlit run app.py
python -m unittest discover -s tests -v
```
